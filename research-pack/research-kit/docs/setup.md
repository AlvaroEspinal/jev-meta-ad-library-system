# Generic Mac setup and rollback

## Offline kit
Requires Python 3.10+ and a browser for the generated static report. Check `python3 --version`, unzip locally, then follow README commands. Do not install packages to run the kit. The report uses no network dependencies. Outputs use new paths and will not overwrite an existing directory/receipt.

## Optional real integration (not supplied or activated)
1. Review current official provider documentation, model identity, terms and pricing from the bibliography. Assess dependency/model provenance and licenses before installation.
2. Pick one narrow labeled workload. Use the included state/question shape; keep the existing implementation as fallback.
3. Configure a dedicated server-side credential with a small budget and appropriate permissions in the operating system's secret store or runtime environment. Do not paste it into a source file, browser, shared prompt or ZIP.
4. Supply your own `VAULT_ROOT`, `EVIDENCE_ROOT`, `DOWNLOADS_ROOT` and runtime paths in a local config, never another person's absolute paths. Validate roots, symlinks, permissions and exact allowlists.
5. Install the separate capture companion/extension only after reviewing its version, permissions and installer dry-run. Do not reuse personal browser profiles for scraping. There is no instruction here to bypass the installation approval gate.
6. Validate fixture/negative cases, then explicitly approve bounded live smoke tests. Record source, provider, resolved model, measured costs and browser cleanup. Run shadow comparison before active mode.
7. An isolated cloud browser needs its own current authenticated provider account. Fail closed if unavailable. No silent local-profile fallback and no Instagram browser access.

## Rollback
Disable active routing and model calls first; preserve evidence/receipts. Stop only the owned coordinator/workers and confirm cloud sessions stopped. Return to the original handler. Disable/unregister the reviewed extension/native host using its package's dry-run uninstall path. Never delete captured notes, secrets owned by other apps, unrelated profiles or cumulative history. The kit itself is inert: removing its local folder removes the kit, not external integrations.
