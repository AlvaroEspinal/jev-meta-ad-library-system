## Not accepted / gates

- No live-source extraction/download tests. DOM adapters and publicness/isolation attestation need current source checks in an approved isolated browser. Never test Instagram through browser.
- Platform-page media resolvers are not implemented. Direct assets or externally reviewed imports only; private/DRM/unsupported fails.
- No Instagram provider dispatch. Jev CLI transport is implemented and mock-tested, but no live API call or active routing was performed.
- Static LP parsing does not reliably extract offer/proof/claims; these remain unclassified unless separately reviewed.
- The local research HTML is implemented; automatic ingestion in existing running cockpit remains unimplemented.

Thus **Workstream 1 is not finished**. Installation is one remaining gate, not an excuse to call unimplemented functionality complete. Workstream 2 has its own self-contained offline acceptance and is not blocked by this gate.
