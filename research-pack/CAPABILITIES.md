# Supported capabilities and remaining limitations

Friend pack: 1.0.0. Research kit: 1.0.0. Extension friend distribution: 0.2.1, based on tested capture 0.2.0. Exact source commits are in VERSION.json.

| Capability | Shipped status | What is NOT established |
|---|---|---|
| Five awareness stages + 15-angle canonical taxonomy | Documentation, structured schema and synthetic examples | Ground-truth labels or predictive ad performance |
| Typed Choice / Score / Noul contract | Offline validator, request/response fixtures, rejection tests | Calibrated model accuracy or confidence |
| Jev inference transport | One-call, dedicated-key, dry-run-default CLI | Current paid endpoint/model acceptance; local Jev weights |
| Extension visible-evidence capture | Public non-Instagram adapters + synthetic DOM tests | Current live platform compatibility or installed Chrome |
| Quick Download | Direct, allowlisted, unsigned HTTPS assets; local collision-safe Downloads | Arbitrary platform page/video resolution, DRM, private media |
| Save to Obsidian | Reviewed source-organized notes, full record, HTML, hash/HMAC receipts | Automatic publishing or client-account writes |
| Instagram | External pasted reference + reviewed non-browser artifact import | Provider dispatch/setup, browser collection of any kind |
| Landing evidence | Explicit allowlisted static HTML headings/CTA candidates | Complete semantic offer/proof/claims extraction; JS/redirects |
| Cockpit | Compatible taxonomy/context and local per-record HTML demonstration | Live ten-browser cockpit runtime or automatic existing-cockpit ingestion |
| Media conversion | Optional local ffmpeg/ffprobe with duration/protocol checks | Hardened codec sandbox or installed external tools |
| Installer | Generic macOS user-only native setup; dry-run default; sandbox verified | Friend's Chrome/OS acceptance; Windows/Linux native support |
| Security checks | Hash manifests, path/PII/secret patterns, negatives, cold tests | Exhaustive security audit or trustworthy source content |

This package intentionally distributes the verified capture baseline, not unfinished source-tree experiments in platform resolvers, provider dispatch, richer LP fields or cockpit ingestion. Those scope gaps remain implementation work, not merely live-install gates. It is ready to share as an accurately labeled **prototype research toolkit**, not as an acceptance-complete universal scraping system. See [detailed capture capabilities](research-capture/docs/capabilities.md).
